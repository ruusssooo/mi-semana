# mi-semana

Planificador semanal personal (universidad, gimnasio, jiu jitsu y tareas propias) en una sola página web, sin instalaciones ni servidor.

Para abrirla: descargá o cloná el repositorio y hacé doble clic en `index.html` (se abre en Safari o cualquier navegador), o publicá el repositorio con GitHub Pages y entrá a la URL que te da.
